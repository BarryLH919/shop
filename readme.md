# Git练习仓库
本仓库主要是用来学习git的操作详细流程

## 🛠️ 目标
- 熟练掌握git/github技能
- 建立目标项目仓库
- 为未来开发任务做准备

## 🚀 进度情况
当前阶段为第三周

### 第一周、第二周内容
前两周为基础git安装、git原理、基础指令、关联github账号-push/pull命令等

### 第三周内容
本周主要内容为设定仓库规范、错误定位与冲突解决、git生存能力等

## 🖥️ 验证标准

### 前两周验收标准
独立建设git仓库，完成三次以上commit
管理git仓库到github
设定git分支，并完成mergr后删除多余分支

### 第三周验收标准
规范仓库内容
完善.gitignore内容
人为制造错误，并发现错误位置
冲突解决方案
分支并行开发合并，创建多working tree、练习rebase
错误时能安全恢复
